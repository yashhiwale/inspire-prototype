# INSPIRE — Intelligent Navigation for Skills, Potential, Industry, Roadmaps & Employment

A fully working, clickable, interactive prototype designed for a high-impact hackathon presentation. Built with **React 18 + Vite + Tailwind CSS + Lucide Icons + React Router v6**.

---

## 🚀 Quick Start (Under 1 Minute)

```bash
# 1. Navigate to the project directory
cd C:\Users\hiwal\.gemini\antigravity\scratch\inspire-prototype

# 2. Install dependencies (Already verified & built!)
npm install

# 3. Launch the development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

## ⏱️ 60-Second Hackathon Judge Demo Script

1. **0:00 - 0:10 (Landing Page `/`)**:
   - Highlight the **Problem** (university theoretical lag) and the **INSPIRE 5-Pillar Solution**.
   - Show the **Support We Are Seeking** (AI/ML mentorship, Govt department pilot, grants) and **Team Cards** (Sanjana, Gayatri, Yash, Samarth — BSc IT).
   - Click **"Launch Prototype Demo"**.

2. **0:10 - 0:20 (Auth & Fast-Track `/auth`)**:
   - Click the orange **"1-Click Demo Login as Student Aarav"** button (bypasses manual typing for judges).

3. **0:20 - 0:30 (Onboarding & 10-Question Diagnostic `/app/onboarding`)**:
   - Step 1: Academic profile.
   - Step 2: 10 psychometric & cognitive questions (rated 1-5).
   - Step 3: Select priority domain track (e.g., Full-Stack Web Dev or AI & Machine Learning).
   - Click **"Generate My Tailored Dashboard"**.

4. **0:30 - 0:40 (Dashboard & Career Explorer `/app/dashboard`)**:
   - Point out the **Target Track**, **Roadmap Progress %**, and **Top 3 Skill Gaps**.
   - Navigate to **Career Explorer** (`/app/career-explorer`) to show the 8 mapped domains with **"Why Recommended"** explainability bullets.

5. **0:40 - 0:50 (Skill Gap & Dynamic Roadmap `/app/skill-gap` & `/app/roadmap`)**:
   - Show the current collegiate score vs. industry benchmark progress bars.
   - Click **"Generate Roadmap"** into `/app/roadmap`.
   - **Click any task checkbox** (e.g., "TypeScript Setup & Strict Mode Config") to watch the **completion percentage recalculate live**, showing immediate celebration toasts and badge minting!

6. **0:50 - 1:00 (Skill Passport & Placements `/app/skill-passport` & `/app/opportunities`)**:
   - In **Skill Passport**, see the verified competency badge earned from your completed task.
   - Click **"Export Passport (JSON)"** to download the verifiable credential payload.
   - In **Opportunities**, click **"Apply"** on a matching job to demonstrate the application flow.
   - *(Bonus)*: Switch to the **Institution Dashboard** (`/app/institution`) to show university dean analytics (NEP 2020 compliance & cohort bottlenecks).
